# --- Identity (auth programme Phase 2) -------------------------------------------------------
# SRP-6a for local password authentication: the password never reaches the server, so it cannot
# appear in a proxy, a memory dump or a debug log. Chosen over an argon2id verifier deliberately
# (brief FR-4); both were on the table and TLS covers a different threat.
#
# Ships as `py3-none-any` and resolves to the pure-Python backend (`srp._pysrp`) — no compiler and
# no OpenSSL ctypes binding, which is what makes it installable at an air-gapped site (FR-4a).
#
# ⚠️ ITS DEFAULTS ARE NOT SAFE. `hash_alg=0` is SHA-1 and `salt_len=4` is a 32-bit salt, so a
# reasonable-looking `create_salted_verification_key(user, pw)` enrols a SHA-1 credential. Always
# pass hash_alg/ng_type/salt_len explicitly — brief FR-4e, enforced by AC-4c and AC-4d.
